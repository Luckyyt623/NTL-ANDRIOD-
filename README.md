# NTL Mobile for Slither.io

NTL Mobile is an Android port of the **NTL Mod for Slither.io**, made so Android players can use the NTL experience with mobile-friendly controls.

The Android port does not claim ownership of the original NTL Mod or Slither.io. Credit for each component remains with its respective creator.

## What is included

NTL Mobile combines the NTL Mod with Android WebView support and SlitherControl+ so the mod can be used on Android devices with touch controls.

The app also includes the NTL Mobile startup screen, update checking, signed APK updates, and the optional ad-unlock flow used by this project.

## Safety & Privacy

NTL Mobile is intended to be safe to use when downloaded from the official release source. The Android port is not designed to access your contacts, photos, microphone, or location, and it does not intentionally include spyware or malware.

The app requires internet access because Slither.io, NTL services, update checking, and optional ad/unlock services are online features. These services can receive normal network information such as your IP address when you connect to them.

For your safety, download the APK only from the official NTL Mobile release repository and verify the SHA-256 checksum when needed. Android may also ask for permission to install app updates from this source.

## Updates

NTL Mobile can check the official public release repository for newer versions. When an update is available, the app can download the new APK and automatically open the Android installer. Android still requires the user to approve the final **Update / Install** step.

## Important

After watching an ad, restart NTL Mobile for the best experience.
